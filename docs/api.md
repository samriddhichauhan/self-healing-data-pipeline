# Backend API Specification

This document details the planned API endpoints for the backend service (`apps/backend`) to bridge the Frontend, Apache Airflow, and the AI Agent.

---

## Status
- **Status**: **PLANNED** (Not yet implemented)
- **Base URL**: `http://localhost:8000/api/v1`

---

## Endpoints

### 1. Pipeline Status
Get current execution metrics and DAG run status from Airflow.
- **URL**: `/pipeline/status`
- **Method**: `GET`
- **Response**:
  ```json
  {
    "status": "healthy",
    "active_runs": 1,
    "last_completed_run": "2026-06-14T02:00:00Z",
    "success_rate": 0.96
  }
  ```

### 2. Incident Logs
List incident reports generated by the AI diagnostic agent.
- **URL**: `/incidents`
- **Method**: `GET`
- **Response**:
  ```json
  [
    {
      "id": "inc_7482",
      "timestamp": "2026-06-05T02:15:32Z",
      "task_id": "validate_quality",
      "fault_category": "volume_anomaly_spike",
      "status": "remediated",
      "remediation_action": "deduplication_merge"
    }
  ]
  ```

### 3. Incident Details
Get evidence, root cause analysis, and proposed remediation for a specific incident.
- **URL**: `/incidents/:id`
- **Method**: `GET`
- **Response**:
  ```json
  {
    "id": "inc_7483",
    "status": "escalated_pending_approval",
    "evidence": {
      "staged_row_count": 12000,
      "historical_average": 300,
      "anomaly_type": "spike"
    },
    "root_cause": "Duplicate batch transmission from upstream server",
    "proposed_action": "idempotent_delete_and_reload"
  }
  ```

### 4. Approve Remediation
Approve an escalated remediation action proposed by the Agent.
- **URL**: `/incidents/:id/approve`
- **Method**: `POST`
- **Body**:
  ```json
  {
    "approved_by": "samri",
    "comment": "Confirmed duplicate ingestion from upstream network retry"
  }
  ```
- **Response**:
  ```json
  {
    "status": "remediating",
    "message": "Remediation command issued to Airflow worker"
  }
  ```
